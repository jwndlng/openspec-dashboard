# Prompt

The installation wizard should first do the base setup:
- Workspace directory: Use the system browser e.g. Finder and let the user select a directory. Also keep the project selection.
- Agent Setup: In this step the user should be able to add any agent CLI he uses, not only one.
- Once Agent setup is done, let the user select the default agent for the global console and explain what it is
- Then for each enabled repo, walk the user through the project settings - show default settings and let the user adjust. We can also say "Project Settings" configure the same settings for all projects or choose individual settings. We then show the defaults in the UI and let the user take adjustments.

Make the UI form a bit bigger and add more spacing to it. This must be a great experience!
