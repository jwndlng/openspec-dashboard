# Prompt

Lets update the current board and simplify the phases into:

Backlog -> Drafts -> Ready -> Implementing -> Done -> Archived

That means we move Proposal, design and specs into one and I would like to see a similar progress bar like it exists for tasks.

Synced and archived become Archived, because it usually done in one step anyway.

The overall idea is to only show phases/steps that are actually interesting for a human.
