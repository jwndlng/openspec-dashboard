# Prompt

Currently discovery of new projects, enabling etc is managed via settings, but it would be more native to the user if its in the project overview. The idea is that all enabled projects are at the top like it is today. Then below there will be a new section "Untracked / Disabled" Projects and they will have an enable button, which will move them up or for some they will have the "enable openspec" or so. So the project discovery and management moves into the projects tab.
